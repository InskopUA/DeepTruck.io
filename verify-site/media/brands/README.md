# Dealership make logos

Used next to the customer dealership names supplied by the project owner.

- Toyota, Ford, Honda, Nissan, Kia, Hyundai, BMW, Audi, Subaru, Mazda,
  Volkswagen, and Chrysler: [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons).
- Mercedes: [Simple Icons 11.0.0](https://github.com/simple-icons/simple-icons/blob/11.0.0/icons/mercedes.svg).
- Lexus: [Lexus Logo.svg, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Lexus_Logo.svg), CC0, by Glebushko0703.

Simple Icons' CC0 license is included in LICENSE.md. Brand marks remain the
property of their respective owners. The multibrand Chicago dealership uses
the Chrysler mark. SVG files are served locally; display color and sizing are
applied with CSS.
